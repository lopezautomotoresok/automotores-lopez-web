# Automotores Lopez - Catálogo starter

## Ejecutar en tu PC
1. Instalar Node.js LTS.
2. Abrir esta carpeta en VS Code.
3. En la terminal ejecutar `npm install`.
4. Ejecutar `npm run dev`.
5. Abrir la URL local que muestre Astro (normalmente http://localhost:4321).

## Publicar
- Subir el proyecto a GitHub.
- En Cloudflare: Workers & Pages > Create application > Pages > Import an existing Git repository.
- Build command: `npm run build`
- Build directory: `dist`
